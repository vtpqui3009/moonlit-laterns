# Nhạc nền riêng

Mặc định phim phát một giai điệu Trung Thu **tự sáng tác**, tạo bằng WebAudio
(`src/audio/festivalTune.ts`), nên không cần file nhạc nào.

Muốn dùng bài của riêng bạn: đặt file vào đây với tên **`nhac-nen.mp3`**.
Khi người xem bấm "Bắt đầu", file này được phát lặp lại thay cho giai điệu tự tạo;
tiếng dế và gió vẫn giữ. Chỉ dùng bản nhạc bạn có quyền sử dụng.
